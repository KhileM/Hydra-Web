## Setup

1. Clone the repo
   git clone https://github.com/YOUR_USERNAME/hydra-dashboard.git
   cd hydra-dashboard

2. Install dependencies
   npm install

3. Create your .env file
   cp .env.example .env
   # Fill in your HYDRA credentials

4. Run locally
   npm run dev

5. Build for production
   npm run build
